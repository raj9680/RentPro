What actually differs

 A · MVC onlyB · MVC + Web API
Where DTOs liveApplication/Features/*/Dtos/Library.Contracts/
Who the UI callsIBookService directlyIBookApiClient over HTTP
Exception middlewareLibrary.UI/Middlewares/Library.Api/Middlewares/
DbContext startup wiringLibrary.UI/Program.csLibrary.Api/Program.cs
Authcookie, validated in-processApi issues the JWT, UI holds it in a cookie
ViewModelsone per screenonly where the shape differs from the contract

Domain, Application and Infrastructure are identical in both. That is the payoff of the layering: going from A to B touches only the two outer projects.
